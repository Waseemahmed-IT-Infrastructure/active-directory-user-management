
# Active Directory User Management

## Overview

This repository documents common user account administration tasks in Microsoft Active Directory.

It covers account creation, account updates, password management and basic troubleshooting.

## User Account Management

Common administration tasks include:

- Creating new user accounts
- Updating user information
- Enabling and disabling accounts
- Resetting passwords
- Unlocking locked accounts
- Moving users between Organizational Units (OUs)
- Reviewing account status and group membership

## Creating a User Account

1. Open Active Directory Users and Computers (ADUC).
2. Navigate to the appropriate Organizational Unit.
3. Right-click the OU and select New > User.
4. Enter the required user information.
5. Set the initial password according to company policy.
6. Review the account settings.
7. Create the account and verify its details.

## Password and Account Management

- Reset passwords after verifying the user's identity.
- Unlock accounts when appropriate.
- Check whether an account is enabled or disabled.
- Review password expiration and account restrictions.
- Follow approved procedures for account changes.

## Basic Troubleshooting

| Issue | What to Check |
|---|---|
| User cannot sign in | Account status and credentials |
| Account locked | Lockout status and related events |
| Password expired | Password status and reset requirements |
| Missing access | Group membership and permissions |
| User not found | Correct domain and Organizational Unit |

## Tools

- Windows Server
